How do I connect?

On your computer, open the Relay launcher or run:

npm start

This opens and pairs the local dashboard automatically. Then choose Connect phone and scan its QR code with your phone. No pairing command is needed on your phone.

Manual fallback only: npm run pair -- create owner creates a code for this local browser. It expires after 10 minutes.
